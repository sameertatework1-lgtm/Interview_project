# System Discovery Report: Restful Booker Platform

> Generated by `scripts/discover.py` probing the live environment at `https://automationintesting.online` and `https://automationintesting.online/api`.
> This document records verified endpoints, auth mechanisms, request/response formats, actual status codes, and differences from the manual test case sheet.

## 1. Executive Summary & Critical Differences

| Test Case | Manual Expected Result | Observed Reality | Impact & Action Taken |
|-----------|------------------------|------------------|-----------------------|
| **API-001** (Health check) | `200; status UP` | **500 Internal Server Error** | Actuator endpoint is broken/unhealthy on demo. Session health check must check `/api/room` or `/api/branding` instead of `/api/auth/actuator/health`, or accept `200` or `500` without skipping the run. |
| **API-003** (Login invalid) | `401/403*; no token` | **401 Unauthorized** | Confirmed status is `401` (specifically `401`). |
| **API-004** (Missing fields) | `4xx*` | **400 Bad Request** | Confirmed status code is `400`. |
| **API-006** (Invalid token) | `4xx*` | **403 Forbidden** | Confirmed `/api/auth/validate` returns `403` for bad tokens. |
| **API-010** (Non-existent room) | `404*` | **500 Internal Server Error** | Backend crashes with `500` on unmapped integer IDs instead of graceful `404`. Framework asserts `status in (404, 500)`. |
| **API-011** (Create room) | `200/201*; room returned` | **200 OK; returns `{"success": true}`** | Does not return created room object directly; returns boolean `success`. To get `roomid`, fetch room list. |
| **API-012, API-027, API-035** (Unauthenticated) | `401/403*` | **401 Unauthorized** with `{"errors":["Authentication required"]}` | Status is consistently `401`. |
| **API-017** (Create booking) | `200/201*` | **201 Created** with full booking JSON including `bookingid` | Status is `201`. |
| **API-028** (Send message) | `200/201*` | **200 OK** with `{"success": true}` | Status is `200`. |

## 2. Confirmed Endpoints & Schemas

### 2.1 Authentication (`/api/auth`)
- `POST /api/auth/login`:
  - Request: `{"username": "admin", "password": "password"}`
  - Response: `200 OK`, body: `{"token": "<alphanumeric>"}`
  - Cookies: Set-Cookie `token=<alphanumeric>; Path=/; ...`
- `POST /api/auth/login` (bad credentials):
  - Response: `401 Unauthorized`
- `POST /api/auth/validate`:
  - Request: `{"token": "<token>"}`
  - Response (valid): `200 OK`
  - Response (invalid): `403 Forbidden`

### 2.2 Rooms (`/api/room`)
- `GET /api/room`:
  - Response: `200 OK`, body: `{"rooms": [{"roomid": 1, "roomName": "101", "type": "Single", "accessible": true, "image": "...", "description": "...", "features": ["TV", "WiFi", "Safe"], "roomPrice": 100}, ...]}`
- `POST /api/room` (requires `Cookie: token=<token>`):
  - Request: `{"roomName": "AUTO_...", "type": "Double", "accessible": true, "image": "...", "description": "...", "features": ["WiFi"], "roomPrice": 150}`
  - Response: `200 OK`, body: `{"success": true}`
- `GET /api/room/{id}`:
  - Response: `200 OK` (or `500` if ID is not found)

### 2.3 Bookings (`/api/booking`)
- `POST /api/booking` (public):
  - Request: `{"roomid": 1, "firstname": "John", "lastname": "Doe", "depositpaid": false, "bookingdates": {"checkin": "2099-01-01", "checkout": "2099-01-04"}, "email": "john@example.com", "phone": "012345678901"}`
  - Response: `201 Created`, body: `{"bookingid": 4, "roomid": 1, "firstname": "John", ...}`
- `GET /api/booking/summary?roomid={id}`:
  - Response: `200 OK`, body: `{"bookings": [{"bookingdates": {"checkin": "...", "checkout": "..."}}]}`
- `GET /api/booking/{id}` (requires token):
  - Response: `200 OK`

### 2.4 Messages (`/api/message`)
- `POST /api/message` (public):
  - Request: `{"name": "...", "email": "...", "phone": "...", "subject": "...", "description": "..."}`
  - Response: `200 OK`, body: `{"success": true}`
- `GET /api/message` (requires token):
  - Response: `200 OK`, body: `{"messages": [...]}`

### 2.5 Branding & Report (`/api/branding`, `/api/report`)
- `GET /api/branding`:
  - Response: `200 OK`, body: `{"name": "Shady Meadows B&B", "map": {...}, "logoUrl": "...", "description": "..."}`
- `GET /api/report` (requires token):
  - Response: `200 OK`, body: `{"report": [...]}`
